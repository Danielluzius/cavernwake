# Cavernwake

A small pixel-art exploration game in a side-view style — built entirely without JavaScript.

🚧 **Work in Progress** — the game is still under active development, scope and content may still change.

## Concept

Cavernwake is a pure HTML/CSS project: movement, animations and interactions are handled entirely through CSS (`:checked` states, sibling selectors, keyframe animations) — not a single line of JavaScript is used.

You wake up lost in a cave system after a fall, separated from your backpack and its light source. Explore the tunnels, ladders and elevators connecting the rooms, find your way back to your gear, and look for a way out.

## Playing

Just open `index.html` in your browser — no installation or build steps required.
